# Регламент релиза учебного проекта Маяк

Это вымышленный документ для проверки AI-инструмента. Он не описывает реальную организацию.
Дата учебного решения: 2020-01-01. Версия примера: 1.

## Подготовка заявки
Заявку на релиз подают за 7 календарных дней до планируемого выпуска.
За 3 дня до выпуска координатор только проверяет комплектность документов.
Число 3 не является сроком подачи заявки.

## Согласование
Для выпуска нужны 2 независимых согласующих: представитель разработки и представитель эксплуатации.
Автор заявки не может засчитываться как один из этих согласующих.

## Контрольный пример
Код контрольного примера: BIRCH-72.
Все положения этого документа синтетические и используются только в тестовом vault.
